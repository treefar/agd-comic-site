0–5 秒：預選動畫角，兩個純文字角色名可切換，按「開始」；5–10 秒：第一隻雜訊怪不攻擊，點它會接近後普攻；10–18 秒：點地上紙團撿起，再點怪投擲，第一片作品拼圖恢復；18–25 秒：技能文字鈕顯示課名，施放後首波必定有足夠能量；25–30 秒：可放奧義清波，出現課程卡，可選「下一波」或「看這門課」。這些秒數是設計目標，需 M2 新手測試，尚無通過率數據。

循環：換線接近 → 普攻／投物累積能量 → 課程技能解圍 → 清波看卡 → 下一個空間。整局戰鬥目標 150–180 秒，卡片停留不計時；看課程不須先通關。

## 5. 操作與戰鬥規則

| 功能 | 桌機 | 手機點擊版 |
|---|---|---|
| 換線／移動 | WASD／方向鍵，斜向速度正規化 | 點空地走過去；再點新位置可中斷，無虛擬搖桿 |
| 普攻 | J，面向最近同線敵人 | 點敵人接近後自動普攻，點空地可解除鎖定 |
| 技能／奧義 | K／L，冷卻／能量不足不執行 | 兩個純文字鈕顯示課名與秒數／能量 |
| 防禦 | 按住 Shift，減傷 60%，速度降為 0 | 按住「防禦」文字鈕；離開按鈕或 pointercancel 立即解除 |
| 撿／丟 | 接近紙團按 E；再按 E 朝鎖定目標丟 | 點紙團走去撿起，再點敵人投擲；不可撿實驗室貴重設備 |
| 暫停 | P／Escape | 暫停文字鈕，切到背景也暫停，回來需按繼續 |

不加入跳躍與指令搓招；角色間碰撞使用邏輯座標，沒有友軍傷害。基準畫布概念座標 1280×720，可行走 x=100–1180、y=300–650；速度 220 px/s，敵我同線判定 y 距離 ≤32 px。指標座標需轉回邏輯座標，不能拿 CSS px 直接比較；手機縮放後的可點目標至少 48 CSS px，普通文字按鈕至少 44 CSS px 高。

手機敵人速度乘 .75、預告延長 200 ms，傷害與課程獎勵不變。直向仍可玩但主場景保持橫幅，文字操作區排在場景外、允許頁面捲動；只在戰鬥區阻止拖曳捲動。手機點擊的代價是精準走位較少；相較搖桿多鍵，手指遮擋與學習負擔較低，需找新手實測驗證，不能當已證明結論。長按角色防禦較難發現且會遮住人物，所以採明示文字鈕。

HP 歸零：凍結戰鬥，顯示「再試本波／看課程」，本關已過波次不倒扣、重試 HP 100。無連續死亡嘲諷、無把真實畢業資格當成評分結果的文案。同機雙人、連線、排名帳號皆為 v2 再說。

## 6. 三關三種手感

所有 px 以 1280×720 計，以下值是起始提案，未實測。各關 twist 不累積，核心輸入與命中規則不變；普通與重擊的頓幀對雙方一致，不修改傷害判定。RM 表示偏好減少動態時關閉的裝飾；音效可獨立靜音。

### 6.1 第 1 關：逐格出手

twist：攻擊姿勢以 12 fps 逐格播，命中仍依固定模擬時間判斷，不讓美術影格率改變輸入延遲。長 1080 px、深度 350 px；中央通路寬 160 px，兩邊各留 100 px 迴避區。兩波各 2 隻雜訊怪，HP 30、速度 90 px/s；首波不攻擊，第二波預告 900 ms、傷害 6、兩次攻擊至少間隔 1.8 秒。目標 35–45 秒、第一個命中 ≤10 秒。

|---|---|---|---|
| 攻擊預備 | 角色原圖壓低再回彈 | scaleY .94→1，83 ms | 關閉縮放 |
| 實際命中 | 攻守雙方頓幀 | 45 ms；揮空不觸發 | 保留同等玩法停頓 |

## 7. 技術與體積

推薦 HTML5 DOM＋原生 JavaScript，DOM img 顯示角色與實景圖，用裁切和 transform 做圖集動作、位移與縮放；碰撞為不可見資料，依地面 y 排序，不把偵錯盒顯示給玩家。四名可選但每局只出選中角色，玩家＋最多 3 敵＋1 紙團，特效實例最多 8。這是本案減少依賴與小量物件的工程取捨，未宣稱有 DOM 優於 Canvas 的實測。

Canvas 僅作備案：如果 DOM 在指定手機達不到 M4 門檻，另案量測後才改；屆時只可顯示核准圖像切片並做位移縮放，不得畫角色、背景或 UI 本體。不得以簡單向量人形充當正式角色，不新增物理引擎／Spine／Phaser 依賴。固定 60 Hz 邏輯步進、渲染插值與輸入佇列為實作規格，API 與版本依實作時官方文件查證，本工單不捏造呼叫簽章。
