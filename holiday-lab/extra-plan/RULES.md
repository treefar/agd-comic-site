# 五款純規則與可回歸測試規格

此檔是待實作規格，不是測試通過證據。共用 `ctx` 不變；節點 id 加各款前綴，Sprite id 必加 `-sprite`，避免既有重複DOM id問題。座標採16:10舞台百分比中心，旋轉先換等比例像素再換回。

## peace-memory｜把話聽完整

- 三位虛構人物各有一張14×18%的訊息區，中心X為20/50/80，Y50。閱讀框可調X/Y及寬度，高度固定26%。每次選人物開始聆聽；訊息區必須完整落框內，連續1.2秒才記錄，移出就中止本次。已收錄不重計；三人順序自由。
- 作品保存實際閱讀框、聆聽順序與訊息；按自己實際順序回放，沒有把「觀點正確」當道德分數。
- 先紅後綠：窄框／偏離／只聽0.3秒不能取得；移開停止；三人不同順序均有效且結果不同；非法座標與NaN拒絕；重開清空；暫停只由ctx停止dt；destroy取消監聽；zh/en/ja皆能操作。

## qingming｜紙鳶借風

- 固定小步長模擬位置與速度；風向、牽線角度／張力／線長實際影響軌跡。三段風各有不同雲間取景窗。停留命中區0.5秒才收一格，漏過可回上一段重試；不以連點完成。
- 保留採樣軌跡、控制調整與三次命中位置。重播至少3段，位置來自真軌跡。
- 先紅後綠：初始不會自動完成三格；過鬆／錯方向無法通過；正確連續操作可通過；相同總dt拆成不同frame量近似一致；NaN／超範圍輸入拒絕；重試保留已完成段但重開歸零；減少動態時仍有位置與文字狀態；三語及destroy。

## labor｜動畫接力班

- 兩段虛構動畫各有草稿10、動作12、上色8個虛擬時間單位，共六件任務。三位動畫師可自由分工，每人負荷不得超過28；同人不可重疊；草稿→動作→上色有前置依賴；一名動畫師有固定休息區間；全部須在50單位內完成。六個開始時間、六個負責人可調；不是原生真實工作排班工具。
- 縮時預覽明標「縮時」，依實際排程讓工作紙在三人位置交接。`artifact`保留每件任務及負荷，三個結果鏡頭展示草稿、動作與完成稿。
- 先紅後綠：未完成／前置顛倒／同人重疊／休息中被派／過量／超時／非法人員都拒絕；至少兩組不同有效排程都通過且回放不同；重開清空、三語、destroy。

## retrocession｜時光對照室

- 三個錨點共同檢查圖像對位，第一關平移、第二關加入旋轉、第三關加入尺度。判定用舞台實際比例的錨點距離；允許小誤差，沒有唯一必抄數字。原創虛構舊新稿不當史料。
- `artifact`保留三次變換與各錨點誤差；回放畫面套真變換。
- 先紅後綠：單一錨點接近不等於成功；錯角度／尺度不可只靠平移通關；非法變換拒絕；剛體旋轉保持相對距離與方向；兩組有效近似變換結果不同；三關皆需完成；三語與清理。

## constitution｜同一頁，都看懂

- 三段預寫三語短字幕。玩家調字級、分行、停留時間、淺／深字幕紙與位置，確保可讀容量、最低遊戲目標字級、對比及不遮擋人物。文字只用DOM動態文字，底圖由Codex生成。遊戲內的設計目標不是法律規定。
- 先以純規則驗容量／時間／安全區，再用真DOM量測字幕實際overflow與字底。紙帶長寬不能拉成壓文字的黑框；沿用九宮格淨空區教訓。
- 先紅後綠：字太小／太快／文字溢出／人物被擋／低對比拒絕；至少兩種不同有效分行與位置都通過；語言長度不同仍有可用解；真DOM字底／像素對比測試；重開、三語、destroy。

## 共通交付

每款獨立 `codex/<短名>` 分支，模組／tests／report一批提交。不push、不碰main、不刪檔，不改root共用外框與交接C節。報告逐條yes/no附真實指令輸出；沒有素材或瀏覽器驗證就列no，不能用純規則測試升格成美術或可玩通過。
