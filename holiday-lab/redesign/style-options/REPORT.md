## 官方依據與本機來源

以下官方指南於2026-10-22查閱；設計判斷為本報告推論，不是W3C指定必須採本方案：

- W3C Reflow：320CSS px下資訊能重排，支持手機一欄與長字不造成橫捲。https://www.w3.org/WAI/WCAG22/Understanding/reflow.html
- W3C Target Size Minimum：24×24CSS px及例外條件；本稿48px是自行設定的較寬裕目標。https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum
- W3C Contrast Minimum：正文對比要求依規範；本稿只選用高對比組合，未做完整認證。https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum.html
- W3C Animation from Interactions／C39：尊重減少動態偏好，保留理解必要資訊。https://www.w3.org/WAI/WCAG21/Understanding/animation-from-interactions 、https://www.w3.org/WAI/WCAG22/Techniques/css/C39.html
- W3C Accordion Pattern：若後續改自訂accordion，標題、button、展開狀態與控制關係需保留。此草稿FAQ採原生details／summary，主流程以獨立區塊＋aria-expanded與焦點轉移，不把APG範例視為已全數實作。https://www.w3.org/WAI/ARIA/apg/patterns/accordion/
- 本機既有系網內容與實際DOM：`source-guide.json`、`baseline.json`；各校處室原始網址保存在每卡sources。沒有把既有新聞當成仍開放報名的證明。
