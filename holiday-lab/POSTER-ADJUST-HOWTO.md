# 海報調整模式使用說明

1. 開 `http://127.0.0.1:8902/?lang=zh&adjust=1`（視窗寬度要 1181px 以上）。左下角會出現「調整模式」面板，輪播會自動停住。
2. 用「上一張／下一張」選海報。直接在海報上按住拖曳可移動位置；拉桿可調「放大」「左右位置」「上下位置」，「標題位置」可強制靠左或靠右。
3. 放大最小 100%（滿版，不留空白）。草稿自動存在這個瀏覽器，重新整理不會消失。
4. 調好後按「複製全部設定」，把內容貼給 Claude；或存成檔案後執行：

```bash
node scripts/apply-poster-adjust.cjs poster-adjust.json
```

   設定值為 `null` 代表回到自動取景。每筆都會先驗證，有任何一筆不合法整份都不會寫入。
5. 一般網址（沒有 `?adjust=1`）看不到這個面板。
