## 必須修正的兩處流程

### 抵免：先依初審調整選課，不等最後核定

[教務處抵免頁](https://www.aca.stu.edu.tw/抵免學分/)官方索引明列5步。應呈現：

系統填寫並印表 → 送交系所初審 → 依初審調整選課 → 文件交註冊課務組 → 查詢最後核定結果。

原三步把調課置於最後核定之後，會使學生錯過加退選。申請身分/期限是前置確認；核定不是自動幫學生退選。[抵免申請書索引](https://wpc.stu.edu.tw/wp-content/uploads/sites/34/2021/02/抵免學分申請書.pdf)另支持成績正本或證明與送審要求。115-1期限已於2026-09-21結束，文字只保留當期公告及程序，不寫成現在仍可申請。

### 休學、復學、兵役：分流辦理

[教務休退學現行頁](https://www.aca.stu.edu.tw/學生休學、復學及退學/)官方索引可核實先聯繫系所、登記領表、辦離校及交回文件；[教務FAQ](https://www.aca.stu.edu.tw/常見問題｜qa/)可核實復學/續休依通知另辦。因此改為休學一路、復學/續休一路，兵役另辦，不畫成休學→復學→兵役的固定3步。兵役只核實[學校公告列表](https://www.stu.edu.tw/latestnews/)有轉入/復學/延畢等生輔提醒，未取得本期附件，不抄舊兵役表單資格。

## 15卡大流程與適用範圍

| 項目 | 大流程 | 範圍 |
|---|---|---|
| 畢業檢核 | 核對入學年度 → 整理未通過項目 → 向系辦確認補修 | 不同入學年與班別分開核對；有缺項就找系辦確認補修或認列。 |
| 校外實習 | 取得當期實習規定 → 確認單位與老師 → 完成合約保險確認 | 這是開始實習前的準備；實習中怎麼聯絡老師、結束後交什麼，也請先問清楚。 |
| 證照認列 | 先查系上認列範圍 → 考取後登錄證明 → 另查獎助資格送件 | 畢業認列與獎助是兩件事；獎助須另查當期資格及期限。 |
| 我要請假 | 確認假別與證明 → 到系統提出申請 → 追蹤簽核結果 | 有考試、較長假期或緊急狀況，先向承辦確認另外要辦的事。 |
| 選課加退選 | 先核對必修與時間 → 依公告初選加退選 → 重開系統確認結果 | 選課成功與課程異動都要再查；已截止的時程不代表仍可補選。 |
| 學分抵免 | 系統填寫並印表 → 送交系所初審 → 依初審調整選課 → 文件交註冊課務組 → 查詢最後核定結果 | 先核對可申請身分與當期期限；初審後的加退選要自己辦，不等最後核定才處理。 |
| 專題製作 | 先取當屆辦法表單 → 與老師排審查進度 → 依要求交作品文件 | 分組、審查日期、作品格式與展演要求，先取得當屆文件再排進度。 |
| 英文門檻 | 核對分級與外語學分 → 確認門檻通過方式 → 完成認列再查檢核 | 英文課程學分與英文能力門檻要分開確認；分級免修也要問清楚補足方式。 |
| 休學復學與兵役 | 想辦休學或退學 ／ 準備復學或續休 ／ 另查自己的兵役事項 | 休學與復學依目前狀況擇一辦理；役男另向生輔組確認兵役，不以完成學籍程序代替。 |
| 獎助與急難協助 | 說明困難與已領補助 → 確認方案備妥資料 → 依期限送件追蹤補件 | 急難慰助、助學金與學雜費減免各有資格和期限，先請承辦協助選方案。 |
| 遇到困難找誰 | 先找師長協助轉介 ／ 需要時預約諮商 ／ 權益事件找正式窗口 | 依需求直接找窗口，不必先諮商才能提出權益問題。 |
| 就業資源 | 準備履歷與作品集 → 詢問師長職發資源 → 依職缺投件並追蹤 | 可同步找師長討論與使用職發資源，依各職缺要求準備作品。 |
| 繼續升學 | 帶作品討論升學方向 → 查當年度簡章資格 → 完成報名並追蹤審查 | 本校與外校各看自己的簡章；送出後仍要查資格審查與補件狀態。 |
| 海外實習 | 先查當期甄選機會 → 核對資格費用與補助 → 錄取後完成行前準備 | 海外實習的甄選、補助與出國文件分開確認；歷屆成果不代表本期已開放。 |
| 海外見學 | 詢問當期見學或課程 → 核對行程費用與認列 → 依文件報名準備出國 | 見學、交換與海外實習的申請和補助不同，依正在招募的團或課程辦理。 |

## 各單位來源如何支持流程

- **教務處**：[FAQ](https://www.aca.stu.edu.tw/常見問題｜qa/)、[分工](https://www.aca.stu.edu.tw/組織簡介｜introduction-2/)、抵免程序與表單、休退學現行頁一併比對。選課/抵免的115-1已過期時程不能延用；不同入學年課表分開查。
- **職發中心**：[業務與成員](https://dcpi.sao.stu.edu.tw/業務介紹-成員/)可核實實習合約、保險與學海業務及就業資源。[證照系統](https://info.stu.edu.tw/sao/certificate/item/index.asp)證實學生填登後由職發審核，但不等於本系畢業認列自動通過。[114-2獎助公告](https://www.stu.edu.tw/latestnews-single/?id=233658)作歷史申請方式參考，不能保證現仍受理。
- **實習全程**：校方113校務計畫第70頁描述線上合約檢核與雙方用印；屬歷史制度說明，不替代本系現行辦法。現有3步只涵蓋開始前準備，實習中/結束後的紀錄、訪視、考核文件仍待本系資料。未套用觀光系週誌裝訂、同意書份數或專科進修學校規則。
- **生輔組**：[急難申請須知](https://life.sao.stu.edu.tw/急難救助/急難慰問/)、[校內獎助目錄](https://life.sao.stu.edu.tw/獎助學金/校內獎助學金/)、[學雜費減免公告](https://life.sao.stu.edu.tw/學雜費減免/教育部學雜費減免/學雜費減免辦理公告/)分開閱讀，各方案資格、文件和期限不能混用。[2026請假簽核公告](https://www.stu.edu.tw/latestnews-single/?id=213183)支持系統提出後還須追蹤簽核；完整請假規則仍缺，不新增補假天數。
- **通識/語文承辦**：修課頁全文可讀，確認入學年度、分級、免修補足與外語修課的關係；頁內114-1選課時程為舊資料。英文能力檢定門檻另有辦法，不能以修足外語學分直接替代。
- **國際處/教育部**：[出國交流入口](https://www.oica.stu.edu.tw/出國交流/)與教育部補助要點分開看。境外生來校交換申請不能當本校生出國流程；本系見學與學海實習也不能互套。
- **招生選才組**：116碩甄系統有填表、審查進度及補件入口；升學準備應提醒送出後追蹤。校內外各所條件依自己的當年簡章，不虛構本系升學核准程序。
- **學生求助與權益**：[在校學生入口](https://www.stu.edu.tw/在校學生/)可核實諮商入口，但不支持完整申訴程序。gender-contact是教職員職場普查，gender-event是活動聯絡，均不作學生程序證據；主控會移除相關卡/FAQ引用，保留source物件歷史。108年學生申訴組織辦法只證明歷史管道存在，不用來填現行受理期限或表單。
