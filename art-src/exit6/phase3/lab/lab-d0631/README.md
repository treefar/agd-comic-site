# lab-d0631「虛擬製片靶場」— D0631 動作捕捉實驗室（虛擬製片棚）

## 1. 遊戲基本資訊
- **實驗室代號與名稱**：`lab-d0631` ｜ D0631 動作捕捉實驗室
- **對應專業技術**：虛擬製片（Virtual Production）
- **遊戲時長**：60 秒倒數計時
- **星等條件**：
  - ★1 通關：總分達 `WIN_SCORE`（60 分）
  - ★2 熟練：總分達 `score2`（100 分）
  - ★3 完美：每箭都上靶（零脫靶，`flawless === true`）

## 2. 情境改寫與專長知識
- **情境改寫**：
  - 靶場是 D0631 動作捕捉實驗室（虛擬製片棚）由大型 LED 牆即時投影出的擬真場景。
  - 玩家扮演穿著光學動捕裝的演員，透過動作捕捉系統即時將拉弓瞄準的肢體骨架與箭矢飛行軌跡合成至虛擬鏡頭畫面中。
  - 畫面上方標示 `LIVE ● 即時合成中`，呈現虛擬製片片場即時預覽監看螢幕的氛圍。
- **專長知識**：
  > 「虛擬製片用 LED 牆即時投出場景，演員一邊演、鏡頭一邊拍，不必等後製才看到成果。」

## 3. 玩法與操作方式
- **遊戲目標**：在 60 秒倒數結束前，觀察風向與靶面擺動，蓄力瞄準射擊，獲得至少 60 分通過驗收。
- **操作方式**（滑鼠、觸控、鍵盤皆支援）：
  1. **按住蓄力（Draw）**：
     - 電腦鍵盤：按住 `Space`（空白鍵）。
     - 滑鼠／觸控：在畫面任一處按住不放，或按住畫面下方的「按住拉弓／放開射擊」按鈕。
     - 蓄力期間準心會動態向內聚焦收縮，最佳聚光時間點為 **1.15 秒**（準心縮至最小、抖動最低、呈現金黃色）；若按住超過 4.6 秒手臂疲勞準心變紅並大幅擴散。
  2. **移動瞄準（Aim）**：
     - 滑鼠移動或手指拖曳滑動，準心隨之移動。
     - 需觀察右上方風向風速（例如 `← 2.5 m/s` 表示強風往左吹，需往右偏瞄補償）。
  3. **放開射擊（Release）**：
     - 放開空白鍵、滑鼠或觸控點，箭矢即時射出並留下動捕光跡。
     - 命中靶面依環數獲得 1～10 分，靶面彈跳並爆發金色粒子；脫靶得 0 分並顯示紅閃。

## 4. 由淺入深難度三階設計
總時長 60 秒，自動切換難度：
1. **第 1 階（0～20 秒）：微風定點測試**
   - 距離：12 公尺
   - 風速：微風 `+0.5 m/s`（極微弱右偏）
   - 靶面大小：1.0x（標準大靶，定點靜止）
   - 特色：新手熟悉蓄力手感與彈道，幾乎不會失誤。
2. **第 2 階（20～40 秒）：側風動態模擬**
   - 距離：20 公尺
   - 風速：中風 `-2.5 m/s`（明顯向左吹拂）
   - 靶面大小：0.85x（靶面微幅左右擺動）
   - 特色：需觀察風向向右預判偏瞄，並掌握擺動週期。
3. **第 3 階（40～60 秒）：強風微型靶捕捉**
   - 距離：30 公尺
   - 風速：強風 `+4.5 m/s`（強烈向右偏折，伴隨下墜）
   - 靶面大小：0.65x（靶縮小且擺動速度加快）
   - 特色：考驗抗壓性與精準修正能力，沉著釋放才能維持每箭上靶。

## 5. 門檻分數推估說明
- **通關分數推估（`WIN_SCORE = 60`）**：
  - 單箭命中靶面環數為 1～10 分（正中靶心 10 分，外環 1～3 分，脫靶 0 分）。
  - 一局 60 秒內，普通玩家平均蓄力約 1.2～1.8 秒射出一箭，全場約射出 12～16 箭。
  - 只要玩家有正常對準靶面、蓄力超過 0.5 秒，平均每箭約可拿到 5～7 分。
  - 12 箭 × 5 分 ＝ 60 分。只要未頻繁脫靶或胡亂秒放，約 **七成** 正常的高中生初次遊玩者皆能在 60 秒內達成 60 分通關。
- **熟練二星門檻推估（`score2 = 100`）**：
  - 掌握風向修正且蓄力節奏穩健的認真玩家，第 1、2 階能穩定命中 8～10 環，全場平均每箭可達 7 分以上。
  - 射出約 15 箭 × 7 分 ＝ 105 分。設定 `score2 = 100`，約能讓 **一半** 認真玩的正常玩家取得第二顆星。
- **完美三星門檻（`flawless`）**：
  - 條件為「每箭都上靶」（`shotsFired > 0 && hits === shotsFired && misses === 0`）。
  - 要求射出的每一箭落點都在靶面直徑內（`radial < 1.0`），考驗在第 3 階強風與動態小靶時不急躁失手。
