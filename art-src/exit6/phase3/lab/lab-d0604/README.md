# lab-d0604「繪圖板描線救援」— D0604 電繪實驗室

## 1. 情境與專長知識
- **實驗室**：D0604 電繪實驗室
- **對應專長**：數位繪圖
- **背景設定**：玩家在走廊走進電繪實驗室，在電繪板畫面上使用數位筆刷（藍線滑行、紅線動力）描繪軌道，引導小圓球角色順利滑到終點旗。
- **專長知識**：
  > 「電繪不只是畫圖，線條的走向與力道決定畫面怎麼「流動」，就像這條線決定角色怎麼滑。」

## 2. 玩法與規則
- **時限**：全域 60 秒倒數計時。
- **連續挑戰**：三階小關卡連續推進（直線 → 跨溝 → 紅線動力）。
- **勝利條件（win）**：60 秒內成功通過 2 關以上。
- **計分公式**：
  $$\text{得分} = \text{過關數} \times 1000 + \lfloor\text{剩餘墨水比例} \times 500\rceil + \text{剩餘秒數} \times 10$$
- **完美條件（flawless）**：
  「每關一次成功」——每一關都在第一次按下『出發』時就直接抵達終點，無中途跌倒、無手動重設。

## 3. 星等門檻與 score2 估算依據
- **★1（通關星）**：`win === true`（過關數 $\ge 2$）。高中生約 60 秒內只要掌握藍線畫坡即有機會通過。
- **★2（高分星）**：`score >= 2500`。
  - **估算依據**：認真遊玩的玩家通過前 2 關時，可獲得基礎分 $2 \times 1000 = 2000$ 分；平均剩餘墨水約 50%～60%（約 250～300 分）；剩餘時間約 20～25 秒（約 200～250 分）。合計總分約在 2450～2550 分。將 `score2` 設在 2500 分，恰好讓正常發揮、走線乾淨的玩家約有一半機率獲得。若技術純熟通關第 3 關，總分將破 3400 分必拿第二星。
- **★3（完美星）**：`flawless === true`（每關一次出發即達終點，零失誤）。

## 4. 操作方式
- **畫布拖曳**：在電繪板畫面上按住拖曳即可畫出筆觸軌道。
- **底部工具列**（觸控區域皆 $\ge 44\times 44$ CSS 像素）：
  - **藍線**（筆刷）：繪製一般平滑滑行軌道（快捷鍵 `1`）。
  - **紅線**（筆刷）：沿筆劃方向給予推力（第 3 關開放，快捷鍵 `2`）。
  - **橡皮**：在線條附近點擊或拖曳可擦除並退還墨水（快捷鍵 `3` 或 `E`）。
  - **出發 ▶ / 暫停 ⏸**：啟動物理模擬或暫停（快捷鍵 `Space`）。
  - **重設 ⟲**：小球回到起點重新編輯（快捷鍵 `R`）。
  - **清空 ✕**：清除當前關卡所有自畫線條並重置墨水（快捷鍵 `C`）。

## 5. 三階難度設計
1. **第一階（第一關 · 滑行斜坡）**：
   - 目標：掌握直線與斜率。從起點平台畫一條傾斜藍線直通終點。
   - 墨水上限：$\infty$。
2. **第二階（第二關 · 跨越斷層）**：
   - 目標：掌握平滑弧度與跨谷。中間斷崖需畫出順暢的橋樑，避免曲率過陡造成小球著地摔倒。
   - 墨水上限：520 px。
3. **第三階（第三關 · 向上加速）**：
   - 目標：掌握切線加速與紅線動力。終點位於高處平台，需先以藍線畫圓弧導引谷底衝力，再以紅線向上加速衝上平台。
   - 墨水上限：640 px。
