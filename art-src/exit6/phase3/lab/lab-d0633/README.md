# lab-d0633「VR 跑步機衝刺」— D0633 體感互動實驗室

## 1. 遊戲基本資訊
- **遊戲 ID**：`lab-d0633`
- **對應實驗室**：`D0633 體感互動實驗室`
- **對應專長**：`體感互動`
- **遊戲時長**：限時 60 秒

## 2. 遊戲情境與玩法
- **情境改寫**：玩家穿戴頭戴顯示器站在 VR 跑步機上，眼前投射出高空虛擬城市的連綿屋頂。畫面四周以科技線條繪製淡淡的「VR 視野框」與運動狀態 HUD。
- **玩法核心**：一鍵奔跑跳躍。角色在虛擬屋頂上自動奔馳，玩家只需要專注於「跳躍」的操作。
- **操作方式**：
  - **鍵盤**：按 `空白鍵`（`Space`）、`W` 或 `方向鍵上`（`↑`）進行跳躍；按住時間愈久跳得愈高愈遠，放開則迅速下墜。
  - **滑鼠／觸控**：按住畫面任意處即可起跳，支援觸控長按與長短跳微操。
  - **教學提示**：開場前 3 秒以顯著標籤提示一行教學：「點畫面或按空白鍵跳躍，按久跳更遠」。

## 3. 由淺入深三階難度設計（寫在 rules.js）
遊戲時間總長 60 秒，分為三段遞增難度：
1. **第 1 階（0～20 秒，初階暖身）**：
   - 速度：200 ～ 280 px/s（加速度 4.0 px/s²）。
   - 地形缺口：最小間隔 26 px，最大間隔為物理跳躍包絡線可達距離之 60%（非常寬容，幾乎不會失足）。
   - 障礙箱：出現機率僅 10%。
2. **第 2 階（20～40 秒，進階提速）**：
   - 速度：280 ～ 360 px/s（加速度 4.0 px/s²）。
   - 地形缺口：最小間隔 38 px，最大間隔為跳躍包絡線之 72%。
   - 障礙箱：出現機率提升至 16%，考驗對起跳時機與滯空長度的控制。
3. **第 3 階（40～60 秒，極限衝刺）**：
   - 速度：360 ～ 440 px/s（加速度 4.0 px/s²）。
   - 地形缺口：最小間隔 52 px，最大間隔高達跳躍包絡線之 82%（極限距離，必須精準按滿跳躍）。
   - 障礙箱：出現機率增至 22%，高速下撞擊減速雖然爭取反應時間，但會損失衝刺距離。

## 4. 勝負條件與選擇說明
- **勝利條件**：**60 秒內沒掉下去並跑滿 60 秒（win = true）**。
- **失敗條件**：中途失足墜下樓頂立即結束（win = false）。
- **設計決策說明**：
  在「跑滿 60 秒」與「達到 WIN_DISTANCE」二擇一中，本遊戲選擇**跑滿 60 秒**。原因在於體感跑步機強調的是節奏維持與耐力完成度；在隨機動態生成的地形中，只要玩家能在逐漸提速的極限衝刺中維持 60 秒不失足墜樓，即代表完整征服這套虛擬訓練，給予明確的成功肯定感。

## 5. 計分與星等機制（Stars）
- **計分（Score）**：累積奔馳距離（公尺，四捨五入取整）。
- **★1 門檻（通關）**：`win === true`（未失足墜樓完走 60 秒）。
- **★2 門檻（認真玩家分數）**：`score >= 1000`（1000 公尺）。
  - **數值推估依據**：
    - 階段 1（0～20s）：平均速度約 240 px/s，換算約奔馳 480 公尺。
    - 階段 2（20～40s）：平均速度約 320 px/s，換算約奔馳 640 公尺（累積達 1120 公尺）。
    - 階段 3（40～60s）：平均速度約 400 px/s，換算約奔馳 800 公尺（累積約 1920 公尺）。
    - 一般高中生或初次遊玩者，前 20 秒極易存活，而在 25～35 秒間會遭遇速度加快與箱子障礙的考驗。認真玩約有一半的玩家能在階段 2 跑到約 33 秒以上（突破 1000 公尺），因此將 `score2` 訂為 1000 公尺。
- **★3 門檻（完美無瑕 Flawless）**：`isFlawless(stats)` 條件為「**全程未撞障礙**」（`stats.win === true && stats.collisions === 0`）。

## 6. 專長知識傳達
- **傳達語句**：
  > 「體感互動把身體動作變成遊戲輸入，跑步機、腳踏車、空間定位都能讓玩家「真的動起來」。」
- **教學意涵**：
  讓玩家體驗到體感互動科技的核心價值在於結合動態硬體與沉浸感視覺回饋，將真實世界的肢體動作轉譯為虛擬世界的奔馳與跳躍。
