# lab-d0628「逐層列印」— D0628 3D 列印工作坊

- **ID**：`lab-d0628`
- **標題**：逐層列印
- **實驗室**：D0628 3D 列印工作坊
- **對應專長**：3D 列印
- **遊戲時長**：60 秒

## 2. 遊戲情境與專長知識
- **情境改寫**：玩家在 3D 列印工作坊操作熱熔沉積（FDM）成型機。從空中落下的四格幾何方塊即為「列印耗材」，透過加熱噴頭逐層沉積。
- **消行意涵**：在 10 寬 16 高的列印平台上，只要將一整橫排鋪平填滿，即代表「列印完成一層」。
- **長高剪影視覺**：畫面右側建置 3D 列印成型機台視覺，包含熱床、雙軸龍門與擠出噴頭。隨著消除層數從 0 增至 8，幾何模型剪影（8 層漸縮幾何瓶/火箭）會由灰盒虛線逐層實體化並帶有藍色擠出層紋，噴頭亦會即時浮動於當前層上方。
- **專長知識**：
  > 「3D 列印是一層一層把模型疊出來，每一層都要穩，模型才不會塌。」
  結算畫面（無論成功或中止）皆會強調此知識點，讓高中生與初學者深刻體會 3D 列印核心製程概念。

## 3. 操作方式
- **開場教學**：畫面上方常駐單行提示：「`←→ 移動、↑ 旋轉、↓ 加速，把一整排填滿就完成一層`」。
- **鍵盤操作**：
  - `←` / `A`：向左平移
  - `→` / `D`：向右平移
  - `↑` / `W`：順時針旋轉（具備 SRS 踢牆）
  - `↓` / `S`：軟落加速（間隔 0.035s）
  - `空白鍵`：直落硬落（瞬間沉積並鎖定）
- **觸控與手機支援**：
  - 底部配置 5 顆虛擬按鈕（`← 左移`、`→ 右移`、`↓ 加速`、`⟳ 旋轉`、`⤓ 直落`）。
  - 按鈕尺寸皆為 48×48px 以上（符合規格要求之 44×44px 門檻），支援 pointerdown 長按連續位移與點擊反饋。

## 4. 三階難度曲線（下落間隔在 rules.js）
- **階級 1（0～20 秒，慢速）**：下落間隔 `0.80 秒`。提供新手足夠的時間辨識材料形狀與規劃擺放位置。
- **階級 2（20～40 秒，中速）**：下落間隔 `0.50 秒`。節奏加快，要求適應旋轉與微調。
- **階級 3（40～60 秒，快速）**：下落間隔 `0.25 秒`。考驗熟練的空間判斷與連續放置反應。

## 5. 勝負、計分與星等評定
- **勝利條件（★1）**：60 秒內累積消除完成 8 層（消 8 行）。
- **失敗條件**：材料堆疊過高頂出出生點（Top-Out），或 60 秒耗盡未滿 8 層。
- **計分方式**：
  - 基礎分：每消除 1 層得 100 分。
  - 多行加成：一次消 2 行額外 +100 分（共 300）、3 行 +300 分（共 600）、4 行 +600 分（共 1000）。
- **二星分數估計（★2，score2 = 1000）**：
  - **估算理由**：通關基本消 8 行單消的分數為 `8 × 100 = 800 分`。認真玩且具備基本技巧的玩家，在 60 秒內通常能達成至少 1 次雙行消除（800 + 100 = 900）加上零星軟落或額外消行，或達成 2 次雙行（800 + 200 = 1000），或抓準長條材料達成一次 4 行大消除（800 + 600 = 1400）。因此將 `score2` 定為 `1000` 分，恰能篩選出「約半數認真且稍具策略的玩家」獲得第二顆星。
- **三星無暇條件（★3，flawless = "列印不溢料"）**：
  - **條件**：獲勝（`win === true`）且全程堆疊最高點從未超過盤面一半（8 格，即盤面 row 0～7 從未有方塊鎖定）。
  - **提示**：盤面於第 8 格位置特別繪製紅色虛線「▲ 溢料警戒線（8格）」，引導玩家穩固底層、避免過度堆高。

## 6. 借用來源與技術保留
- **借自舊檔**：`src/retro/games/tetris.html`
- **保留的手感與機制**：
  1. **SRS 旋轉系統與踢牆表**：保留 `KICKS_JLSTZ` 與 `KICKS_I`，讓方塊貼牆、貼底旋轉時能滑入空隙。
  2. **DAS／ARR 水平移動手感**：DAS 延遲 0.14 秒，ARR 重複頻率 0.035 秒，兼顧單格微調與長按快速靠牆。
  3. **鎖定延遲（Lock Delay）**：落地後具備 0.5 秒緩衝時間，且微調或旋轉可重置延遲（上限 15 次）。

- **改寫與創新**：
  - 盤面縮減為 10 寬 16 高，更符合 60 秒快速微型挑戰。
  - 完全擺脫外部 CSS/JS 依賴，以 Web Audio API 即時合成所有音效。
  - 嚴格遵守六色灰盒規範（紙 `#f4ecd8`、墨 `#0f0d0a`、紅 `#e63946`、黃 `#ffd60a`、藍 `#1d4ed8`、灰 `#8a948e`）。
