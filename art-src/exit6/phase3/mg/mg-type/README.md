# mg-type「字體對撞」小遊戲雛形

- **小遊戲 ID**：`mg-type`
- **對應專長**：視覺傳達設計（Visual Communication Design）
- **遊戲時長**：上限 60 秒（三階節奏）

---

## 1. 遊戲核心理念與專長知識

《六樓出口》視覺傳達設計專長關卡。

在視覺傳達設計中，**文字不只是符號，更自帶鮮明的「個性」與「情緒」**。設計師的核心專業之一，就是為每一則訊息、每一件產品挑選最精準的字型、色彩與版面，讓觀者在第一眼便能感受到訊息的力量與氛圍：

- **粗黑體（Heavy / Sans-Serif）**：
  - **擂台個性**：重量級、撞得遠（高質量與強擊退力）。
  - **視傳應用**：大標題、警示號誌、戶外巨幅看板與強調重點，呈現現代、堅定、力量與醒目感。
- **明體（Serif / Songti）**：
  - **擂台個性**：起落筆鋒銳利、反擊強（受到撞擊時反彈對手大量衝量）。
  - **視傳應用**：書籍雜誌長篇內文、典雅文藝排版、人文品牌，橫細豎粗且易讀性極佳。
- **圓體（Rounded Sans）**：
  - **擂台個性**：高彈性、回彈快（高恢復係數、衝刺冷卻極短）。
  - **視傳應用**：兒童繪本與教材、食品包裝、社群友善指標與休閒品牌，傳遞溫暖、親和與無距離感。
- **楷體（Kai / Script）**：
  - **擂台個性**：靈活自如、轉向極快（角速度與機動性最高）。
  - **視傳應用**：文化節慶、文創商品、證書獎狀與古典意境，體現書法筆勢與歷史底蘊。

## 2. 玩法與規則

1. **開場字陣設定**：
   - 玩家可輸入 1～3 個中文字（預設為「動遊系」，可直接按開始）。
   - 從四種字體風格中選擇一種，賦予字陣專屬的物理能力。
2. **圓形擂台對撞**：
   - 玩家與電腦各率領自組的字陣在圓形擂台上旋轉對撞。
   - 透過瞄準與抓準衝刺時機，將對方的文字全部撞出圈外即獲得勝利！
3. **時間限制與勝負判定**：
   - 60 秒上限。
   - 若將電腦所有文字擊飛出場，立即判定獲勝！
   - 60 秒時間到時：優先比雙方留在場內的文字數量；若字數相同，則比殘存耐久度（HP）總和判定勝負。

## 3. 操作方式

遊戲完全支援三種操作介面，且支援手機直向（375×812）與寬螢幕（1280×720）：

- **滑鼠 / 觸控操作**：
  - 點選或拖曳擂台：設定衝刺瞄準方向。
  - 點放或點擊左下角「衝刺」大按鈕（尺寸大於 44×44px）：發動強力衝刺。
- **鍵盤操作**：
  - `Space`（空白鍵）：發動衝刺。
  - `WASD` 或 `方向鍵`：微調字陣牽引方向。
  - `Enter`：開場對話框快速開始。

---

## 4. 三階難度設計

- **第 1 階（0～20 秒）暖身對撞**：
  - 擂台開闊（半徑 280px）。
  - 電腦對手動作遲緩、追擊侵略性低（Aggression 0.25），玩家能輕鬆上手掌握碰撞手感。
- **第 2 階（20～40 秒）電腦追擊**：
  - 電腦開始主動鎖定玩家字陣並加速逼近追撞（Aggression 0.70，速度提升至 95）。
  - 考驗玩家抓準反作用力與衝刺避讓時機。
- **第 3 階（40～60 秒）決死縮圈**：
  - 擂台劇烈縮小（半徑自 250px 平滑收縮至 190px），圈外邊緣閃爍紅色危險警示。
  - 電腦全面進入高速狂暴猛攻（Aggression 1.00，速度 135），出界判定極度敏銳，進入白熱化絕殺對決！

## 5. 系統字型與退回機制（Fallback）

依據規範，本小遊戲不載入額外外部網路字型，僅使用 CSS 系統字：

- **黑體**：`"Microsoft JhengHei", sans-serif`
- **明體**：`"PMingLiU", serif`
- **圓體**：`"Arial Rounded MT Bold", "Microsoft JhengHei", sans-serif`
  - *退回說明*：若系統未內建 Arial Rounded MT Bold，會自動退回至微軟正黑體及系統 sans-serif。
- **楷體**：`"DFKai-SB", "BiauKai", serif`
  - *退回說明*：若非 Windows 環境或未安裝標楷體，會退回至系統預設 serif 襯線體。

## 6. 參考舊雛形與演化紀錄

- **參考來源**：`src/wordspin/wordspin.html`（原創灰盒姓名對戰雛形）。
- **借用與改寫段落**：
  1. **多文字陣列旋轉幾何**：參考舊檔之多點旋轉字陣概念，改寫為支援 1～3 字動態排列（單字居中、雙字對稱、三字正三角）的純幾何函式 `computeGlyphPositions`。
  2. **物理動量與擊退計算**：借用舊檔中依字體質量、彈性、衝量以及反擊力計算擊退速度之核心公式，重構為純函式 `calcKnockback`，收錄於 `rules.js`。
  3. **去蕪存菁與規範對齊**：
     - 完全移除原檔的遊戲名稱、線上對戰與預設特定姓名。
     - 改寫為單機對電腦模式，並依據視傳專長需求建構四字體個性設定。
     - 導入嚴格的「灰盒漫畫風」規範（紙墨黃紅藍灰六色、3px 粗黑邊框與 4px 硬陰影、右下角 `GRAYBOX` 標記）。
     - 加入完整的 WebAudio 即時合成音效、10 秒教會教學提示、縮圈視覺回饋與結束畫面專長教育卡。
