# mg-anim「時間曲線滑翔」

- **遊戲 ID**：`mg-anim`
- **對應專長**：電腦動畫（Computer Animation）
- **核心定位**：《六樓出口》招生網頁遊戲專長微型雛形，高中生在 60 秒內一玩就懂動畫師的核心技藝。

---

## 1. 玩法與操作方式

玩家控制一個具有彈性形變的滑翔角色，在連續平滑的丘陵地形上飛馳：
- **按住（Pointer Down / Touch / 空白鍵 / 向下鍵 / Z 鍵 / J 鍵）**：角色變重、向下強力俯衝。
- **放開（Pointer Up / 放開按鍵）**：角色變輕、維持空氣動力學滑翔。
- **節奏韻律**：
  - **下坡按住**：順著斜坡重力加速貼地衝刺（緩入積蓄動能）。
  - **上坡前放開**：順著陡坡的向上拋射力衝向高空（緩出釋放動能）。
  - 順應節奏可連續彈飛，越飛越高、越衝越快；若節奏錯亂（上坡重壓或平地摩擦）則會減速失速。

---

## 2. 60 秒三階難度推進

遊戲設有 60 秒總時限，畫面上方顯示倒數進度條，並依秒數推進三個難度階段：
1. **第 1 階（0～20 秒）平緩曲線**：
   - 坡道起伏平緩（低振幅 `amp: 40`、低頻率 `freq: 0.0052`），容錯率極高，引導玩家熟悉「下坡按、上坡放」的基本拍點。
2. **第 2 階（20～40 秒）起伏加劇**：
   - 坡道明顯變陡（高振幅 `amp: 65`、中頻率 `freq: 0.0068`），下坡俯衝加速度激增，騰空滯空感強烈。
3. **第 3 階（40～60 秒）連續小丘**：
   - 連續高頻起伏地形（密集小浪 `amp: 54`、高頻率 `freq: 0.0108`、高粗糙度 `rough: 0.80`），節奏加快，考驗玩家極為敏銳的時機反應。

---

## 3. 勝負判定與關鍵影格旗

賽道上豎立著 3 座「關鍵影格旗（Keyframe Flags）」：
- **KF 01（預備動作 Anticipation）**：約 4,800 單位距離
- **KF 02（極值動作 Extremes）**：約 10,500 單位距離
- **KF 03（完成動作 Follow Through）**：約 16,200 單位距離

- **勝利條件**：在 60 秒時限內飛越全部 3 座關鍵影格旗即獲勝。獲勝時依剩餘秒數與完美緩入次數結算高分。
- **失敗條件**：倒數 60 秒結束時，若尚未飛過第 3 座關鍵影格旗則結算挑戰結束。

## 4. 動畫專長知識（教學意涵）

- **時間曲線（Timing / Value Curve）**：
  在 Maya、Blender 或 After Effects 的 Graph Editor（曲線編輯器）中，動畫師絕不使用生硬的等速直線運動，而是透過調整貝茲時間曲線來控制物體動態的快慢與節奏。
- **緩入緩出（Slow In & Slow Out）**：
  任何具備質量的物體在加速與停下時都需要時間。本遊戲中「下坡貼地重壓蓄速（緩入 Ease-In）」與「順坡拋飛極速滑翔（緩出 Ease-Out）」完美呼應了動畫十二法則中的「緩入緩出」，讓高中生直觀體驗質量、慣性與動態韻律。
- **結束畫面傳達**：
  結束時呈現專長短語：*「這就是電腦動畫在做的事：動畫師用『時間曲線』控制快慢，透過『緩入緩出』讓動作產生自然的重量感！」*

---

## 5. 額外功能：即時「速度曲線」折線圖小窗

畫面左下方常駐一個模擬動畫編輯器（Graph Editor）的即時「速度時間曲線（Timing Curve Widget）」小圖：
- 即時記錄最近約 75 幀的速度變化，繪製為平滑藍色折線。
- 在當前速度端點與極值點標記動畫關鍵影格菱形標記（◆）。
- 讓玩家在操作時能「看見」自己創造出的速度曲線起伏，直觀對照動畫曲線的物理手感。

## 6. 舊檔借鏡與重構說明

- **參考舊檔**：
  - `src/retro/games/tiny_wings.html`
  - `src/retro/engine/retro-core.js`
  - `src/retro/engine/retro-audio.js`
- **借用部分**：
  1. 多重正弦波諧波疊加的地形幾何演算法（`createHills`、`groundAt`、`slopeAt`）。
  2. 貼地滑行沿坡加速度分解（`along = -slope / sqrt(1 + slope^2)`）與起飛拋射向量物理計算。
  3. Web Audio 即時頻率合成短音邏輯。
- **改寫與完全自給自足**：
  1. **零外部依賴**：完全不引入 `src/` 或外部 CSS/JS/字型/圖片資源，所有物理、繪圖、音效在 `rules.js` 與 `game.js` 內自成閉環。
  2. **純規則抽取**：地形運算、速度更新、三階判定、勝負判定完全抽離為無 DOM 依賴的純函式庫 `rules.js`，供 `test.cjs` 進行 100% 確定性單元測試。
  3. **灰盒漫畫風重構**：移除原檔所有位圖與商標，改以紙墨紅黃藍灰 6 色色塊、3px 粗黑邊框與硬陰影、幾何彈性質感角色的漫畫風呈現，右下角固定標註 `GRAYBOX`。
  4. **嚴格介面遵循**：對齊 `EXIT6_MG["mg-anim"].mount(root, api)` 宿主契約，完整支援 `destroy()` 清理所有定時器、事件監聽與 AudioContext，杜絕記憶體洩漏與二次綁定。
