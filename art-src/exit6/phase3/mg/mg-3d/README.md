# mg-3d「3D 列印拼裝」（專長：3D 角色與 3D 列印）

## 1. 玩法說明
- 畫面中央為 3D 列印機的「列印底座」，上方設有方塊組成的凹槽缺口。
- 上方浮空懸掛待列印的零件（2～5 塊方塊組成的多方塊）。
- 玩家必須觀察零件在 3D 空間中的姿態，透過旋轉按鈕調整軸向，使其與底座缺口完全吻合後按下「放下」。
- **正確放入**：完成列印，獲得分數並觸發火花噴濺粒子特效，進入下一題。
- **角度錯誤**：零件碰觸底座彈起，畫面震動並扣除 2 秒時間懲罰，且進入 1 秒防亂按冷卻鎖定。
- **勝負條件**：在 60 秒限時內成功完成 5 題即獲勝；時間耗盡則失敗。

## 2. 操作說明
- **視角旋轉**：
  - 在畫面上以滑鼠或手指拖曳（Pointer Events），可在斜上 45° 基礎上微調水平繞看角度（限制 ±30°）與仰俯角（限制 ±15°）。
- **零件旋轉控制**：
  - **繞 X 軸轉 90°**：點擊「轉 X 軸」按鈕，或按鍵盤 `X`。
  - **繞 Y 軸轉 90°**：點擊「轉 Y 軸」按鈕，或按鍵盤 `Y`。
  - **繞 Z 軸轉 90°**：點擊「轉 Z 軸」按鈕，或按鍵盤 `Z`。
  - **放下列印**：點擊「📥 放下」按鈕，或按鍵盤 `Space`（空白鍵）/ `Enter`。放錯時進入 1 秒冷卻，期間放下按鈕變灰且不可用，但轉軸按鈕仍可操作。

## 3. 難度三階設計
- **第 1 階（題目 1～2，0～20 秒）**：
  - 零件為 2～3 塊方塊（雙聯連桿、L 型轉向板）。
  - 目標缺口僅需單一軸向（Y 軸或 Z 軸）轉動一次即可吻合，適合初學者 10 秒內直覺理解。
  - 若答錯，零件旁會顯示「試試看轉 <正確軸> 軸」提示。
- **第 2 階（題目 3～4，20～40 秒）**：
  - 零件為 4 塊方塊（T 型承座、三維立體角構件）。
  - 需要連續轉動兩個不同軸向方能吻合，考驗空間坐標轉換。
- **第 3 階（題目 5，40～60 秒）**：
  - 零件為 5 塊非對稱立體多方塊（機械關節）。
  - 方塊延伸至三個維度且無中心對稱性，需綜合三軸旋轉與空間感知。

## 4. 傳達之專長知識
> **「3D 建模要想清楚物件的方向與軸向，3D 列印前要擺好『列印方向』才不會失敗。」**
- 3D 角色建模與列印技術中，空間三軸（X/Y/Z）的正向與列印切片方向（Print Orientation）至關重要。
- 本遊戲讓高中生親自動手轉動 3D 零件，感受建模座標系轉換與列印平面的幾何對位。

## 5. 程式碼來源與借用說明
- 本小遊戲為**全新撰寫**，無既有舊雛形借用。
- 3D 彩現採用 Three.js r128（固定 CDN 連結，一般 script 標籤載入）。
- 規則核心 `rules.js` 為純整數數學邏輯（不依賴 Three.js 與 DOM），供 `node:test` 獨立驗證。

## 7. 2026-10-16 主控驗收修正
1. **防止連續亂按與冷卻鎖定**：
   - 放錯後進入 1 秒冷卻鎖定（`dropLockUntil = now + 1000`）。
   - 冷卻期間「放下」按鈕變灰且顯示「⏳ 冷卻中」，空白鍵無效，畫面上亦顯示「⏱ 冷卻中」徽章。
   - 轉軸按鈕（X/Y/Z）在冷卻期間保持可用，方便玩家立即修正旋轉姿態。
2. **懲罰扣時調整**：
   - 答錯扣除秒數由 3 秒調降至 2 秒（`PENALTY_SECONDS = 2`），大幅提升容錯率與遊戲體驗。
3. **新手引導提示**：
   - 第 1 階前兩題（題目 1、2）答錯時，在零件 3D 空間位置旁顯示動態提示框「試試看轉 <正確軸> 軸」（例如「試試看轉 Y 軸」）。
   - 提示軸向透過廣度優先搜尋（BFS）最短旋轉路徑動態算出。
4. **規則核心與單元測試擴充**：
   - `rules.js` 新增純函式 `hintAxis(piece, slot)`（回傳 `'x'|'y'|'z'|null`，已吻合時回傳 null）與 `canDrop(now, lockUntil)`。
   - `test.cjs` 更新為 2 秒懲罰驗證，並新增規則 9（`canDrop` 鎖定判定）與規則 10（`hintAxis` 最短旋轉步數有效性），保證每題 hint 轉一次後之步數比轉前少或已吻合。
5. **共通修正**：
   - 移除遊戲內部結束畫面卡片上的「再玩一次」按鈕，保留勝負、分數與專長知識，重玩邏輯交由宿主頁面統一管理。
