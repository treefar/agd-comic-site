# mg-book「繪本跳跳：角色設計」（專長：繪本與角色造型）

本小遊戲是台灣樹德科技大學動畫與遊戲設計系招生網頁遊戲《六樓出口》的走廊專長互動體驗之一。

---

## 1. 玩法與目標

- **目標**：在 60 秒限時內向上彈跳爬升至 80 公尺高的「繪本封面頁」，沿途收集散落的幾何角色特徵配件。
- **特色**：角色會自動彈跳，玩家只需專注在左右落點空間判斷。收集到的帽子、眼睛、圍巾、手持配件會即時穿戴在角色身上，並在結算畫面中完整拼裝出專屬幾何角色，展現「剪影（Silhouette）＋特徵配件」的角色造型奧祕。

---

## 2. 操作說明

- **觸控／滑鼠（Pointer Events）**：
  - 點按畫面左半邊向左移動、點按畫面右半邊向右移動。
  - 支援按住左右拖曳微調落點。
  - 按鈕與可點選範圍皆大於 44×44 CSS 像素，手機直拿（375×812）與電腦橫向（1280×720）皆能舒適遊玩。
- **鍵盤**：
  - 方向鍵 `←` / `→` 或鍵盤 `A` / `D` 鍵控制左右移動。
- **空間特性**：
  - 左右螢幕邊緣相通（從左側飛出會由右側穿回，熟練玩家可利用邊界抄近路）。

---

## 3. 難度三階（0～60 秒節奏曲線）

遊戲依據剩餘時間自動遞進三階難度，右上角即時顯示階段名稱：

1. **第 1 階（0～20 秒，起草打底）**：
   - 平台寬度 90px，平台間距密集（48～64px），無移動平台，零件掉落率高（75%）。
   - 幾乎不會跌落，讓高中生與新手在 10 秒內熟悉「自動彈跳＋左右選擇」的純粹樂趣。
2. **第 2 階（20～40 秒，剪影修邊）**：
   - 平台寬度收縮至 68px，間距略增（56～74px）。
   - 出現 25% 左右移動平台（橫移速度 55px/s），考驗玩家在滯空期間預判落點的時機感。
3. **第 3 階（40～60 秒，封面著色）**：
   - 平台寬度縮減至 50px，移動平台比例高達 50%（速度 85px/s），間距 65～82px。
   - 接近 80m 高空時會升起金黃燦爛的「繪本封面特等席」平台，踩上即刻全破！

## 4. 傳達的專長知識：繪本與角色造型

- **核心概念**：**「角色造型靠『剪影＋特徵配件』讓人一眼記住！」**
- **原理教學**：
  - 在繪本與角色設計中，一個優秀的角色即便在遠處、黑白草稿、或抽離所有色彩成為「純黑剪影（Silhouette）」時，讀者也必須能光憑外輪廓一眼認出。
  - 角色頭頂的高帽或貝雷帽拉開了垂直高度；飄揚的紅色長圍巾勾勒出動態線；手持的羽毛筆或魔法杖拉開了側邊水平寬度；大眼睛則注入角色的靈魂。
- **結算畫面教學實踐**：
  - 結算時同時呈現**【剪影外輪廓】**（純墨黑 Silhouette）與**【繪本著色】**（幾何配件拼裝）雙重視角對比。
  - 依據玩家實際收集到的配件組合，給出客製化造型評語（例如：「頂部、臉部、頸部與側邊特徵全齊！剪影外輪廓極具故事性與辨識度」、「有帽子和圍巾，剪影辨識度很高！」、「純粹的幾何原型！繪本角色造型的第一步就是穩固的基礎幾何」等）。
  - 最後總結：「這就是 繪本與角色造型 在做的事：用簡單鮮明的幾何剪影與配件，創造出翻開書頁就能一眼烙印在讀者心中的經典角色。」

## 5. 借用了舊檔哪幾段

參考舊雛形：`src/retro/games/doodle_jump.html` 與相關引擎模組。

- **借用的物理與算法**：
  1. **垂直彈跳拋物線**：借用下墜接觸平台時的反彈重設邏輯（`player.vy = BOUNCE_SPEED`，下墜時才判斷踩踏，上升時可自由穿過平台）。
  2. **垂直可達性保證**：
     - 理論跳躍高度 $h_{max} = \frac{v^2}{2g}$（約 130.67px）。
     - 借用其「取理論高度 75% 為間距絕對安全上限」的保證機制，相鄰平台間距嚴格 $\le 82\text{px} < h_{max}$，保證絕不出現無解死局。
  3. **水平射程限制**：
     - 借用「以上一塊平台中心 $\pm 140\text{px}$ 範圍內生成新平台」的手感限制，確保角色滯空橫移速度能夠平順銜接。
  4. **單向上升鏡頭**：
     - 借用鏡頭只向上追蹤不向下滑落的手感設計，高度數值只增不減。
  5. **左右螢幕相通**：
     - 借用水平座標穿透包絡計算。
- **改寫與清理項目**：
  - 原檔名稱、舊商標、外部圖檔貼圖 atlas、網路請求讀取、頁面轉址全部移除。
  - 規則邏輯抽取至純函式模組 `rules.js`，完全不依賴 DOM / window，供 `node:test` 自動化測試。
  - 美術嚴格遵守灰盒規範：以色塊、幾何形狀（矩形、圓形、多邊形）、粗黑邊框（3px）與硬陰影（4px 4px 0 墨色）呈現，右下角固定標註 `GRAYBOX`。
  - 音效採用純 WebAudio 即時頻率合成短音（跳躍彈跳、配件拾取、勝利歡呼、失敗頓挫），無任何外部音檔依賴，且在第一次玩家手勢後才解鎖 AudioContext。
  - 內建 `prefers-reduced-motion` 檢測，關閉螢幕震動保護敏感玩家。

## 6. 檔案清單

- `mg/mg-book/index.html`：試玩頁（16:9 居中舞台、掛載遊戲、支援再玩一次與結果回調）
- `mg/mg-book/game.js`：遊戲核心渲染、輸入控制、果汁回饋、自適應畫布與 WebAudio
- `mg/mg-book/rules.js`：純邏輯運算（平台生成、跳躍保證、三階參數、碰撞、收集、評語、勝負）
- `mg/mg-book/test.cjs`：8 個 `node:test` 測試，涵蓋勝負、三階難度、RNG 決定性、浮點公差、幾何碰撞、評語邏輯與共通修正檢驗
- `mg/mg-book/README.md`：本說明文件
