## 怎麼重跑驗證
```
node --test art-src/exit6/phase3/mg/mg-anim/test.cjs
node art-src/exit6/phase3/smoke/smoke.mjs http://localhost:8082/art-src/exit6/phase3/mg mg-anim
```
冒煙測試要先開本機伺服器（`.claude/launch.json` 的 `exit6-src`），而且一次只跑一個遊戲：多分頁同時跑時背景分頁畫面更新被降速，倒數會停住（2026-10-16 實測誤判）。Browser pane 隱藏時 `requestAnimationFrame` 也不跑，不能拿來實玩。

## 接進《六樓出口》還缺的
1. 宿主介面：在走廊遇到老師 → `EXIT6_MG[id].mount(div, { onEnd, rng })` → 結束發簽名卡。
2. 老師對應：使用者挑 4～5 位並取得本人同意後，才把名字與立繪放上去。
3. 真人試玩：mg-type、mg-code 的難度要人玩過才能定。
